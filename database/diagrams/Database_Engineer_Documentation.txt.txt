1. PROJECT OVERVIEW
============================================================

AgriBridge is a farmer-focused digital platform designed to
support agricultural listing and order management.

The database manages farmers, crop listings, buyers, and
orders. It maintains relationships between these entities
using primary keys and foreign keys and ensures data
integrity through relational database constraints.

============================================================
2. DATABASE OBJECTIVE
============================================================

The main objective of the database is to:

1. Store farmer information.
2. Store agricultural crop listings.
3. Store buyer information.
4. Store order information.
5. Maintain relationships between farmers, listings, buyers,
   and orders.
6. Enforce referential integrity using foreign keys.
7. Support reliable database queries and testing.
8. Provide a structured database foundation for the AgriBridge
   application.

5. DATABASE RELATIONSHIPS
============================================================

The final database contains the following relationships:

1. farmers.id → listings.farmer_id

   One farmer can have multiple listings.

2. listings.id → orders.listing_id

   One listing can be associated with orders.

3. buyers.id → orders.buyer_id

   One buyer can be associated with multiple orders.

Relationship structure:

FARMERS
   |
   | 1 : N
   |
LISTINGS
   |
   | 1 : N
   |
ORDERS
   |
   | N : 1
   |
BUYERS

============================================================
7. FOREIGN KEYS
============================================================

The following foreign keys are implemented:

1. listings.farmer_id
   REFERENCES farmers(id)

2. orders.listing_id
   REFERENCES listings(id)

3. orders.buyer_id
   REFERENCES buyers(id)

Foreign keys ensure that related records remain valid and
prevent invalid references between tables.
